### 2. TRACE — Satellite-Based Oil Spill Detection & Source Attribution

A college-level Smart India Hackathon (SIH) project focused on detecting potential marine oil spills using Sentinel-1 SAR imagery and connecting detections with GIS, drift modelling, and AIS vessel data.

**My Contribution — AI/ML & SAR Detection:**

- Processed Sentinel-1 SAR imagery
- Worked with SAR backscatter data
- Implemented threshold-based oil-spill candidate detection
- Generated binary oil-spill masks
- Applied connected-component analysis and spatial filtering
- Generated georeferenced `oil_mask.tif`
- Evaluated detection using Precision, Recall, and Dice score
- Investigated cross-scene generalization and adaptive thresholding
- Established a baseline for future ML-based segmentation
